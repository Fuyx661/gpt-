## 信息与固定合同域

DSO只得到当前聚合基线、节点、类别及公开额定/服务上界 qbar。BESS充电时公开互斥使qbar=0，否则为额定放电功率；CL取公开基线、最低运行及服务限制，不用剩余预算；EV取当前聚合基线，不用逐车能量或可达性。qbar不是交付保证。每期询价前生成 q=.5*qbar、q=qbar，零合同隐含允许，每Provider至多授标一份；真实能力只在Provider内部或独立离线诊断使用。

Provider端点仍为四状态。策略边界适配器隐藏拒绝原因，扩展阈值 tau=(C+κ)/E（物理不可履约为无穷）。普通REJECT将最低可接受网格价下界推进至下一档，最高档拒绝退出；技术未决不更新。物理拒绝不在首档直接剪枝或终止。对同一状态，物理拒绝与高经济成本拒绝产生相同查询历史的受控测试已通过。未实现跨合同推断，不以推断接受授标。

## EV目标、能量与重排

每辆车维持固定目标 e_req；合成请求为初始无服务功率×连接时长，e_req=e0+eta*请求电量，去掉旧.65–.85缩减。ACN选项用申报请求/交付代理，不反推真实SOC、容量或成本，且不再使用旧1/.8超额基线。

独立充电器、T_after=(departure-t)*dt下：

```
need = max(0, e_req-e_t)
p_min = max(0, (need-eta*Pmax*T_after)/(eta*dt))
0 <= q_v <= p0_v-p_min
e_next = e_t + eta*(p0_v-q_actual_v)*dt
```

要求基线及目标在功率、接入、电池容量下可行；不可达不裁剪成可行。候选合同由最小线性成本的逐车削减分配兑现。实际执行后才计算剩余任务均摊计划：p_future=max(0,e_req-e_next)/(eta*剩余连接时长)。该计划可以超过旧基线，但不得超过Pmax或容量；目标不降、询价不重排。对于独立充电器，此可达性约束与均摊计划相容；不包含共享站约束、V2G或全周期全局最优。

## P/Q和经济证书

节点P=背景+当前资源基线-DG-实际正向柔性。CL/EV的ΔQ=q*tan(acos(PF))，BESS只改变额外P，基线充电PF=1；CL=.95、EV=.99为登记S类假设。新旧基线差仅在当前预测/实际P/Q登记一次，外生误差不变。FNA、有限差分代理、组合AC、Oracle和实际检查同入口。

价格域.20:.05:1是合成研究域，不是市场价格上限；整数档位、接受锁价、无二次确认。执行需当期接受记录和相同q的AC见证，未授标不消耗服务状态，所有设备仍按实际基线演化。

L0为公开域、单授标、既定FNA总量约束下的乐观支付MILP有效全局界；未知物理/经济可行性允许留在外松弛内。U由实际接受且AC可行组合产生。普通PF失败只影响可行上界搜索，不收紧L0。故有效证据和固定状态下L0≤P*≤U，正L0且(U-L0)/L0≤.1时U≤1.1P*；零支付另证。**P*包含同一FNA硬约束**，不把该证书推广到删除FNA约束的仅电压问题；FNA工程参考未证明是后者的必要最小量。无可靠网络排除时不称其为Lnet；Oracle不参与在线停止。

a、b为合成货币/kWh，κ为每正能量合同的合成货币最低净收益。fixture.c对应数学基础a，fixture.a为旧版未用二次项。线性状态成本及紧迫度为建模假设，非创新贡献、非实测校准。κ/E在小合同上可很高，不虚构接受价格，不调低κ或抬高价格上限制造成功。保留0/1/2状态成本对照和实际失败。
