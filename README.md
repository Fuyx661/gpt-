# GPT 对话知识库

用于保存与 GPT 交流中产生的有价值内容，将重要讨论沉淀为可检索、可复用的个人知识。

## 收录内容

- **研究与学习：** 研究思路、论文讨论、知识总结。
- **技术与开发：** 代码问题、技术方案、工作流程。
- **思考与决策：** 重要观点、问题分析、决策记录。
- **提示词与经验：** 可复用的提示词、方法和实践经验。

## 收录原则

优先保存有长期参考价值的对话与结论，不追求完整记录所有聊天。整理时尽量保留必要背景、关键讨论、最终结论和待办事项。

## 目标

让有价值的 GPT 对话能够持续积累、方便查找，并在后续研究、学习和工作中重复使用。
